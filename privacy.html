1. Про застосунок

BCE-PRO — персональний застосунок, який використовує лише його розробник для керування власним YouTube-каналом. Він не призначений для інших користувачів.

2. Які дані застосунок використовує

Після надання дозволу через Google OAuth застосунок отримує доступ до даних YouTube-каналу власника в межах запитаних дозволів (scopes): відео, метадані відео та показники каналу. Застосунок не збирає дані інших осіб.

3. Як використовуються дані

Дані використовуються виключно для функцій застосунку: підготовка й публікація відео, керування метаданими та аналіз каналу власника. Дані не продаються, не передаються третім особам і не використовуються для реклами чи навчання моделей ШІ.

4. Зберігання

Токени доступу та дані зберігаються локально на пристрої власника й не передаються на сторонні сервери, окрім викликів офіційних API Google/YouTube. Доступ можна відкликати в будь-який момент на сторінці myaccount.google.com/permissions, після чого локально збережені токени слід видалити.

5. Відповідність політикам Google

Використання та передача отриманої від Google API інформації будь-якому іншому застосунку відповідатимуть Політиці щодо даних користувачів у сервісах Google API, зокрема вимогам Limited Use. Застосунок також дотримується Умов використання YouTube та Політики конфіденційності Google.

English

1. About the application

BCE-PRO is a personal application used solely by its developer to manage their own YouTube channel. It is not intended for other users.

2. Data the application uses

After the developer grants consent via Google OAuth, the application accesses the developer's own YouTube channel data within the requested scopes: videos, video metadata and channel analytics. The application does not collect data about any other person.

3. How data is used

Data is used solely to provide the application's features: preparing and publishing videos, managing metadata and analysing the developer's channel. Data is not sold, not shared with third parties and not used for advertising or for training AI models.

4. Storage

Access tokens and data are stored locally on the developer's device and are not sent to any servers other than the official Google/YouTube APIs. Access can be revoked at any time at myaccount.google.com/permissions, after which locally stored tokens should be deleted.

5. Compliance with Google policies

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The application also complies with the YouTube Terms of Service and the Google Privacy Policy.

For privacy questions: stepanzapisotskyi@gmail.com
