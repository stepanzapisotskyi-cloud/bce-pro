BCE-PRO

Personal tool for managing a YouTube channel

Українською

BCE-PRO — персональний застосунок для автономного ведення власного YouTube-каналу: підготовка та публікація відео, керування метаданими й аналіз показників каналу. Застосунок створений для особистого використання його автором і не є публічним сервісом.

Застосунок працює лише з YouTube-каналом власника та лише з його дозволу через Google OAuth.

Політика конфіденційності

English

BCE-PRO is a personal application used by its developer to manage their own YouTube channel: preparing and publishing videos, managing metadata and reviewing channel analytics. It is not a public service and is not offered to other users.

The application accesses only the developer's own YouTube channel, and only with the developer's consent via Google OAuth.
